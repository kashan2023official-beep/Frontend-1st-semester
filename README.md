# 🏢 Hostel Management System (HMS)

Welcome to the **Hostel Management System (HMS)** — a modern, responsive, and centralized front-end interface designed for managing university hostels efficiently.

This project was built to streamline processes like room allocation, student registration, mess management, and complaint tracking through an intuitive, beautifully designed dark-themed UI.

## ✨ Key Features

- **🎓 Student Management**: Dedicated pages for new student registration (`student-registration.html`) and viewing student records (`student-records.html`).
- **🛏️ Room Management**: Real-time room availability overview (`room-availability.html`) and room allotment interface (`room-allotment.html`).
- **🍽️ Mess & Dining**: Interfaces to check the weekly mess menu (`mess-menu.html`) and manage mess billing/invoices (`mess-billing.html`).
- **🛠️ Issue Tracking**: Built-in complaint registration page (`complaints.html`) for residents to report maintenance or administrative issues.
- **🚨 Emergency Contacts**: Quick access to essential contacts for security, medical, and administrative staff (`emergencycontacts.html`).
- **📱 Responsive Design**: Fully responsive layout optimized for desktop, tablet, and mobile viewing.

## 🛠️ Technologies Used

The user interface was crafted with modern web development standards, focusing on high performance, maintainability, and aesthetic appeal:

- **HTML5**: Semantic markup for clear structure and accessibility.
- **Tailwind CSS**: Utility-first CSS framework (via CDN) for rapid UI development and custom styling.
- **Vanilla JavaScript**: Used for interactive UI elements such as dropdowns and navigation toggles.
- **Modern UI Patterns**: Implements glassmorphism (backdrop filters), smooth CSS transitions, custom scrollbars, and a sleek dark theme (`#100E34` Navy, `#4F48EC` Blue, `#FFBF18` Gold).
- **Google Fonts**: Uses the **Inter** font family for crisp, professional typography.

## 🚀 Getting Started

Since this is a static frontend project, no complex setup or backend server is required to view the interface.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kashan2023official-beep/Frontend-1st-semester.git
   cd Frontend-1st-semester
   ```
2. **Open the application:**
   Navigate to the `static/` directory and open `home.html` in any modern web browser to start exploring the system.
